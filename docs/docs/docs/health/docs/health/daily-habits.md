# How Can Daily Habits Affect Your Health?

Health is influenced by repeated everyday behaviors, not only by exercise or diet.

## Common habits

Sleep patterns, food choices, physical activity, screen time and stress management can all contribute to how you feel.

## Small changes

You do not need to change everything at once. Try one practical improvement, such as walking more, drinking water regularly, eating more vegetables, or creating a consistent sleep schedule.

Small habits become meaningful when they are repeated consistently.
