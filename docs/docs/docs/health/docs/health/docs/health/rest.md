# Signs That You May Need More Rest

Feeling tired all the time, struggling to concentrate, sleeping poorly, becoming unusually irritable, or losing interest in normal activities can be signs that your routine needs more recovery time.

## Make room for recovery

Sleep, short breaks, movement, relaxation and time away from screens can all help create a healthier daily rhythm.

Rest is not laziness. It is part of maintaining physical and mental well-being.

Persistent or severe symptoms should be discussed with an appropriate healthcare professional.
